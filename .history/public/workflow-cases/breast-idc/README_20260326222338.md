# breast-idc 文件说明

本目录用于乳腺浸润性导管癌病例（BRCA）的前端展示资源。

## 目录与文件含义

### 1) 根目录图片
- uploaded.jpg
  - 含义：步骤01（WSI上传）展示图。
  - 命名：固定为 uploaded.jpg。
  - 数量：1 张。

### 2) 高注意力切片
- 目录：high-attention/
- 文件：patch-1.jpg 到 patch-12.jpg
  - 含义：步骤03/04中使用的高注意力 patch 切片图。
  - 命名：patch-{n}.jpg，n 从 1 开始连续编号。
  - 数量：12 张（当前页面按 12 张读取）。

### 3) 相似 WSI 缩略图
- 目录：similar-wsi/（在 data/clam_run/(在/data3/pathoinsight/code/download_script/data/clam_runs/tcga_project10_full_unique923/coords/masks下面找到就行)
- 文件：similar-1.jpg 到 similar-12.jpg
  - 含义：步骤04（相似检索）右侧相似 WSI 对应图。
  - 命名：similar-{n}.jpg，n 从 1 开始连续编号。
  - 数量：12 张（与 patch 一一对应）。

### 4) 相似病例诊断文本
- 目录：similar-diagnosis/
- 文件：similar-diagnosis.json
  - 含义：步骤04每一条相似病例的诊断文案。（在/home/zcy/test/test_tcga_pathology_final_merged_washed.json文件里面找到对应的就行）
  - 命名：固定为 similar-diagnosis.json。
  - 数量：1 个文件，内部 items 建议 12 条。

推荐 JSON 结构：

{
  "caseId": "breast-idc",
  "items": [
    {
      "index": 1,
      "diagnosis_text": "完整诊断描述",
      "summary": "前端优先显示的摘要"
    }
  ]
}

### 5) 报告文件
- 目录：report/
- 文件：diagnosis-report.pdf
  - 含义：步骤05（报告生成）展示与下载的 PDF。
  - 命名：固定为 diagnosis-report.pdf。
  - 数量：1 个。

## 命名规则
- 全部小写。
- 使用英文短横线连接。
- 编号必须连续，不要缺号。
- 扩展名建议保持 .jpg（图片）与 .pdf（报告）。

## 数量要求汇总
- 根目录：uploaded.jpg（1）
- high-attention：patch-1.jpg ~ patch-12.jpg（12）
- similar-wsi：similar-1.jpg ~ similar-12.jpg（12）
- similar-diagnosis：similar-diagnosis.json（1，items 建议 12）
- report：diagnosis-report.pdf（1）
